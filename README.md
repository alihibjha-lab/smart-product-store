# Smart Product Store

## Project Overview
Smart Product Store is a responsive product management website developed using HTML, CSS and JavaScript. It allows users to view, search, filter, add and delete products easily.

## Objective
The objective of this project is to create a responsive and interactive website using the concepts learned during the internship, including HTML, CSS, JavaScript, DOM manipulation, events, arrays, objects and functions.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Main Features
- Display products dynamically
- Search products
- Filter products by category
- Add new products
- Delete products
- Form validation
- Responsive design for desktop, tablet and mobile devices

## Project Structure
- `index.html` – Main webpage structure
- `style.css` – Website styling and responsive design
- `script.js` – JavaScript functionality
- `images/` – Image and asset folder
- `README.md` – Project documentation
